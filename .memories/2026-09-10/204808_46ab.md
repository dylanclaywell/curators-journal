## Phase 3 complete: the quest dataset is committed

`src/data/quests.json` exists — **214 quests, 106 KB minified** — generated by
`scripts/build-quests.ts` and committed. Phase 4 (engine + queue UI) is next.

### What stage 4 added (commit e8d826c)

- **The dataset**, sorted by id with sorted requirement lists so regeneration diffs
  cleanly instead of looking like a rewrite. Pretty-printed on purpose: committed and
  reviewed by hand, and Vite minifies it into the bundle anyway.
- **A hard guard before writing:** every prerequisite must resolve to a quest in the same
  file or generation throws. A dangling prerequisite would leave the queue referencing a
  quest no completion could ever satisfy.
- **`--check`**: compares the committed dataset to the live wiki using only the inventory
  and revision ids (no page content, ~7 small requests), exits non-zero on drift. It
  flagged `A Ruff Situation` as edited within minutes of the first dataset being written —
  a live demonstration that the wiki moves under us.
- **`src/data/quests.sources.json`**: title -> revision id, committed beside the dataset,
  never shipped (the client has no use for 214 revision numbers, and nothing imports it).

### Type corrections the real data forced
- `difficulty` is now `QuestDifficulty | null` — three miniquest pages carry a numeric
  value the template forbids.
- Removed `kudos` and `barbarianAssault` from `QuestRequirements`: quest pages only
  template quest points and combat level, so the generator could never populate them.
  Bone Voyage's 100 kudos survives as a note. **No field in the type the generator can't fill.**

### Verified numbers
214 quests (20 miniquests), 381 skill requirements, 276 prerequisite edges (8 start-only),
99 notes, 346 quest points available, all prerequisites resolve, acyclic with deepest
chain 8 (Song of the Elves). Bundle unchanged at 293 KiB — nothing imports the dataset yet.

### Decisions made this phase (all in ROADMAP.md with reasoning)
1. **Source:** per-quest-page templates, not Cargo (absent) or `Module:Questreq/data`
   (21 quests behind).
2. **Recipe for Disaster:** ten subquests are first-class, parent is a display group.
3. **`requiredToStart` annotates, doesn't gate** — provisional until used on device.
4. **On disagreement the page wins and generation continues** — the page is what a player
   sees if they check the wiki, so matching it avoids contradicting their source. The
   cross-check exists to find parser bugs, not to referee.
5. **Ironman requirements dropped knowingly** — 20 known cases, deferred to a Later phase.

### Left undone, deliberately
A **weekly GitHub Action** running `--check` and opening an issue on drift. Touches
`.github/workflows` and interacts with open question 5 (deploy job has no
`workflow_dispatch`), so the shape is the user's call. ROADMAP notes it should carry a
manual trigger from the start.
