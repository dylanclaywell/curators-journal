## StageScape Phase 0 — scaffold complete

New project: an OSRS companion PWA shaped as a **docked rail** for iPad Stage Manager (narrow panel beside the game). Core features planned: dependency-ordered quest queue + live hiscores.

### What was built

Full scaffold, verified green (`typecheck`, `lint:check`, `format:check`, `build`, renders with no console errors):

- Vue 3 + TS, Pinia, vue-router, Tailwind v4, `vite-plugin-pwa`, localForage — stack lifted from `../gotorecipe`
- `src/panels/registry.ts` — **panel registry**; routes are generated from it
- `src/lib/types.ts` — shared client ↔ Function shapes (skills, hiscores, quests)
- App shell: header + `RouterView` + bottom `TabBar`, only the panel body scrolls
- `src/style.css` — `@theme` tokens, warm-dark palette + single gold accent, no webfonts
- CI (`ci.yml`: typecheck/lint/format/build) + `release.yml` with release-please (`release-type: node`, custom `data` changelog section), manifest at 0.1.0
- `scripts/build-icons.mjs` — rasterizes `public/icons/icon.svg` to PWA/iOS PNGs via sharp
- `CLAUDE.md`, `README.md`, `wrangler.toml`, `public/_routes.json`

### Key decisions

- **OSRS hiscores expose no quest state** — this shapes the whole product. Quest completions are user-owned, hand-entered, unrecoverable data; hence export/import and the auto-cascade seeding model.
- **Quest data is static and committed** (`src/data/quests.json`, generated by a script) rather than queried live — the app must work offline on iPad.
- **Container queries, not viewport breakpoints** — Stage Manager resizes to arbitrary widths, so media queries lie. Narrow-first (~340–420px) is the design target.
- **Panels as the composition unit** — the seam a future plugin system plugs into, paid for upfront since it's nearly free.
- Everything third-party goes through a Pages Function: hiscores sends no CORS headers; wiki APIs want a `User-Agent`, a forbidden `fetch()` header.
- `overrides: { sharp: "^0.35.4" }` clears 3 high advisories from wrangler→miniflare without downgrading wrangler.
- Repo convention: **no `Co-Authored-By` trailer** on commits (user confirmed), Conventional Commits, ask before committing.
