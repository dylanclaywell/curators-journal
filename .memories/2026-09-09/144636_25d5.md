## Adopted "Quest Journal" art direction

User rejected the initial scaffold's look as generic/AI-generated (correctly — it was near-black + single amber accent + thin stroke icons, a known generated-design cluster). Built three full mockup artifacts, user picked the diegetic **Quest Journal** direction.

### Art direction, now codified in CLAUDE.md

Parchment body / oak chrome / beveled edges drawn as OSRS draws them (light top-left, dark bottom-right), quest journal's red-amber-green state colours, `.engraved` hard 1px black text shadow on oak only.

- `src/style.css` — full `@theme` token set + `.bevel` / `.bevel-in` / `.bevel-oak` / `.bevel-oak-in` / `.pressable` / `.engraved` / `.tap` / `.nums` primitives
- Type: **IM Fell English** (display) + **Alegreya Sans** 400/700 (body), **self-hosted** in `public/fonts` (108 KB total). Reversed the earlier no-webfonts call — that decision cost all typographic personality to solve a problem subset woff2 already solves.
- App icon + PNGs regenerated on the journal palette; manifest/theme colours updated

### Icons — real packs, vendored

- `scripts/build-icon-set.mjs` generates `src/lib/icons.ts` from **game-icons.net** (CC BY 3.0: checklist, hourglass, padlock, open-book) + **Phosphor** bold (MIT: chart, check, gear, external, search, plus)
- game-icons ship a black 512×512 background plate + white foreground; script strips it and hands fill to `currentColor`
- `PanelDefinition.icon` is now an `IconName` key, not a path string — stays JSON-serializable for a future plugin manifest. Icons carry their own viewBox (512 vs 256 grids).
- New `AppIcon.vue` render component

### Mobile-first (user directive mid-turn)

Hard rules now in CLAUDE.md: 44px `.tap` floor on everything interactive, press states on `:active` **not** `:hover` (touch has no hover), hover styling only inside `@media (hover: hover)`, no info behind hover, 16px base font floor (iOS input-zoom threshold).

### Jagex Fan Content Policy — researched

- §8.1 mandates an exact attribution notice — now in README, needs an About panel too
- §2.4 excludes trademarks: never use Jagex/RuneScape logos
- §6.1.2 forbids third-party _clients_ — we read public HTTP hiscores, so not one
- Sprites in a third-party tool: **not addressed**; OSRS Wiki copyright page doesn't cover game images. Resolved by shipping **no Jagex artwork** — game-icons silhouettes stand in for skill icons.
- Policy grants Jagex a broad irrevocable sub-licensable licence over fan content. Flagged and accepted.

### Also fixed

Active tab colour was silently broken: `active-class="text-gold"` lost to base `.text-muted` because both are single-class selectors and Tailwind emitted muted later. Now bound conditionally so only one colour class ever exists.
